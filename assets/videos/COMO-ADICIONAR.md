# Vídeos do site — Dr. Felipe

Coloque os vídeos nesta pasta (`assets/videos/`). Assim que estiverem aqui,
eu conecto cada um no lugar certo do site.

## Onde os vídeos entram

| Arquivo sugerido | Onde entra no site | Formato ideal |
|---|---|---|
| `hero-bg.mp4` | Vídeo de fundo do topo (hero) | horizontal 16:9, sem áudio, curto em loop |
| `hero-bg.webm` | Mesmo vídeo do hero (versão leve p/ web) | horizontal 16:9 |
| `apresentacao.mp4` | Vídeo de apresentação do Dr. (se quiser uma seção) | horizontal 16:9 |

> **Dica p/ o vídeo de fundo do hero:** o ideal é um clipe **curto (5–15s) em loop, mudo e leve**
> (de preferência já comprimido). Se possível, envie também uma versão `.webm` — ela pesa
> menos e carrega mais rápido no navegador.

## Peso dos arquivos (importante)

Vídeo é pesado. Para o site carregar rápido:
- Hero/fundo: tente manter **abaixo de ~5 MB** (comprimido, 1080p ou 720p).
- Se o vídeo for grande, me avise — posso orientar a compressão ou usar um
  player externo (YouTube/Vimeo) em vez de subir o arquivo direto no repositório.

> O GitHub aceita bem arquivos até ~50 MB por commit; acima de 100 MB ele bloqueia.
> Por isso, prefira sempre a versão comprimida.

## Como subir

**Opção A — Google Drive:** coloque os vídeos numa pasta do seu Drive e me diga
o nome da pasta. Eu baixo e subo pro repositório.

**Opção B — Você mesmo sobe:** arraste os arquivos para esta pasta e faça commit,
ou use o "Add file → Upload files" na interface do GitHub, apontando para
`assets/videos/` na branch `claude/dr-felipe-benthien-site-jafgiq`.

**Opção C — Links / YouTube / Vimeo:** se o vídeo já está hospedado, me manda o
link que eu embuto no site (bom para vídeos maiores, sem pesar o repositório).
